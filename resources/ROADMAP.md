# Learning Roadmap


1. Algorithms 
 - Abdul Bari (Youtube channel https://www.youtube.com/watch?v=0IAPZzGSbME&list=PLDN4rrl48XKpZkf03iYFl-O29szjTrs_O) - the best resource for fundamental alignment
 - Michael Sambol (youtube channel https://www.youtube.com/@MichaelSambol/featured) - learn DS and Algo basics
 - Visual Algo (https://visualgo.net/en) - this page uses visualizing tools to simplify how algos are working


Mastering DS and Algos is fundamentally important before continue to the next phases. You are note expected to remember them all for the bits and bytes but you must have the knowledge and practice to later identify patterns in real questions.

2. Neetcode Blind 75 - https://neetcode.io/practice/practice/blind75
Solve couple questions every single day. It is perfectly fine to view the solution video.
Most important is to be able to reproduce those answers a week later.

3. Practice Pattern Based Learning (algomaster https://algomaster.io/) - one of the best approaches is to identify the pattern of a question before starting to solve it

4. Develop your question solving workflow
   a. As you start solving a problem, first write down the DS and Algo you identified
   b. Write a pseudocode version of the solution - this will allow the interviewer classify your understanding of the question and even allow him to pass you even if you code wasn't working by the end of the interview
   c. Write notes of any Q you've solved including challanges, goods and beds, tips. It can assist you as cheatsheet later on.

5. Prepare for specific (big) Tech company - https://seanprashad.com/leetcode-patterns/
